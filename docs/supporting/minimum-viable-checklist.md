# Minimum Viable Civilization Checklist

This combines the core path with the most helpful parallel capabilities into tiers. Focus on completing each tier before heavily investing in the next.

## Tier 0: Survival and Foundations (Years 0–5)

- [ ] Fire-making (`foundations.fire`) — friction, later flint-and-steel
- [ ] Charcoal production (`energy.fuels.charcoal`) — controlled pyrolysis
- [ ] Basic stone and wood tools (`foundations.tools-basic`)
- [ ] Agriculture surplus established (`foundations.food-agriculture`)
- [ ] Animal domestication for labor (`foundations.food-agriculture`)
- [ ] Basic mining and prospecting (`mining.prospecting`) — copper, iron, quartz, limestone, clay, sulfur
- [ ] Pottery and kilns (`ceramics.pottery`)
- [ ] Writing system developed (`knowledge.writing`)
- [ ] Standardized basic measurements (`measurement.precision-metrology`)
- [ ] Sanitation and basic health practices (`health.sanitation`)
- [ ] Basic shelters and organization
- [ ] Basic cordage and rope from natural fibers (`textiles`)

## Tier 1: Industrial Base (Years 5–20)

- [ ] Copper smelting and bronze alloying (`metals.copper`, `metals.bronze`)
- [ ] Iron bloomery smelting → wrought iron → steel (`metals.iron-steel`)
- [ ] Basic metalworking tools (anvils, hammers, files, tongs)
- [ ] Water/wind power harnessing (`energy.gravity`, `energy.wind`)
- [ ] Basic glass production (`glass.basic`)
- [ ] Machine tools bootstrap — charcoal foundry operational (`machine-tools.casting`)
- [ ] First crude lathe built and iteratively improved (`machine-tools.iterative-bootstrap`)
- [ ] Precision metrology expanding (`measurement.precision-metrology`)
- [ ] Steam power developed (`energy.steam-power`)
- [ ] Electricity generation — first generators operational (`energy.electricity`)
- [ ] Bulk chemistry beginning (`chemistry.acids`) — sulfuric acid production
- [ ] Transportation and logistics network (`transport`)
- [ ] Mechanical computing aids available (`computing.mechanical`) — slide rules, calculators
- [ ] Advanced ceramics and refractories (`ceramics`)
- [ ] Printing press operational (`knowledge`)
- [ ] Roads and basic transport infrastructure (`transport.roads`)
- [ ] Lubrication with animal fats and vegetable oils established (`chemistry.lubricants`)
- [ ] Underground mining techniques developed — ventilation, drainage (`mining`)
- [ ] Basic textile production — spinning, weaving, canvas (`textiles`)

## Tier 2: Semiconductor Capability (Years 15–40)

- [ ] Full machine shop operational — shaper, mill, drill press, grinder (`machine-tools.iterative-bootstrap`)
- [ ] Reliable electricity generation and distribution (`energy.electricity`)
- [ ] Chemical industry producing: H₂SO₄, HCl, HNO₃, HF, NaOH, Na₂CO₃ (`chemistry.acids`, `chemistry.alkalis`)
- [ ] Electrolysis producing: Cl₂, H₂, O₂, NaOH (`chemistry.electrolysis`)
- [ ] Vacuum pumps and chambers operational (`gas-handling.vacuum`)
- [ ] Glass apparatus (`glass.advanced`)
- [ ] Basic optics (`optics.inspection`)
- [ ] Metallurgical-grade silicon produced in arc furnace (`silicon.mg-si-production`)
- [ ] Silicon purification pathway operational (`silicon.purification`) — directional solidification or chemical
- [ ] Czochralski crystal growth producing single-crystal ingots (`silicon.crystal-growth`)
- [ ] Wafer slicing, lapping, and polishing (`silicon.crystal-growth`)
- [ ] First solar cells fabricated and generating power (`silicon.basic-devices`)
- [ ] Basic diodes and transistors working (`silicon.basic-devices`)
- [ ] Specialty gases supply chain (`chemistry.air-separation`) — argon, nitrogen, hydrogen
- [ ] Basic cleanroom or glovebox capability (`photolithography.cleanrooms`)
- [ ] Energy storage — lead-acid battery banks (`energy.storage`)
- [ ] Knowledge/education system scaling (`knowledge.education`) — trade schools, libraries
- [ ] Petroleum distillation or alternative organic chemistry feedstocks available (`chemistry.petroleum-alternatives`)
- [ ] Aircraft capability — small piston engine, airframe assembly, fabric covering (`transport.aviation`)
- [ ] Polymer capability — vulcanization, Bakelite molding, fiberglass production, epoxy formulation (`polymers`)

## Tier 3: Advanced and Self-Sustaining (Years 30–100+)

- [ ] Photolithography capability — masks, exposure, alignment (`photolithography.resists-masks`)
- [ ] Photoresist production — novolac + sensitizer (`photolithography.resists-masks`)
- [ ] Core fab processes: oxidation, etching, CVD, doping, metallization (`photolithography.fab-processes`)
- [ ] First integrated circuits (SSI/MSI) (`photolithography.fab-processes`)
- [ ] Wafer packaging, wire bonding, encapsulation (`chemistry.packaging-testing`)
- [ ] Wafer probing and parametric testing (`chemistry.packaging-testing`)
- [ ] Early computers/controllers operational from own ICs (`computing.electronic`)
- [ ] Cleanrooms at laminar flow level with ultrapure water (UPW) (`photolithography.cleanrooms`)
- [ ] VLSI scaling in progress — smaller features, more layers (`vlsi-scaling.continuous-scaling`)
- [ ] Advanced lithography scaling — DUV development (`vlsi-scaling.advanced-lithography`)
- [ ] High-end solar cells (PERC-like) in production (`vlsi-scaling.advanced-processes`)
- [ ] Full computing ecosystem + EDA tools (`vlsi-scaling.eda-design`)
- [ ] Comprehensive recycling and circular systems
- [ ] Specialized workforce training institutions (universities) (`knowledge.education`)
- [ ] Advanced packaging (flip-chip, chiplets) in development (`vlsi-scaling.eda-design`)
- [ ] GPU-scale VLSI design capability (`vlsi-scaling.eda-design`)

## Success Criteria for "Minimum Viable"

- Can produce usable solar cells and basic ICs
- Has redundant energy, transportation, and knowledge systems
- Can train the next generation of specialists
- Has positive feedback loops (early chips improve tools and processes)
