Bearings, abrasives, and cutting tools are the precision enablers of machine tool construction. This article is now split into two focused articles:

- **[Bearings](bearings.md)** — Plain (journal) bearings with babbitt metal lining, rolling element ball bearings (52100 steel), bearing selection guide, and bearing lubricants.
- **[Abrasives & Cutting Tools](abrasives.md)** — Natural abrasives (emery, sandstone), synthetic abrasives (SiC, Al₂O₃ from electric arc furnace), grinding wheel construction, lapping and honing, thread cutting, tap and die production, and cutting tool materials (carbon steel, HSS).

For the machine tool construction sequence, see [Iterative Bootstrap](./iterative-bootstrap.md). For the machining operations that use these tools, see [Machining](./machining.md).
