# Brazing & Soldering

> **Node ID**: `machine-tools.joining.brazing-soldering`
> **Domain**: [Machine Tools](./index.md)
> **Dependencies**: None
> **Enables**: [`chemistry`](../chemistry/.md), [`metals.alloys`](../metals/alloys.md)
> **Outputs**: brazed_joints, soldered_joints
> **Timeline**: Years 5-30
> **Critical**: No

Filler alloy joining methods where the base metal does not melt. Brazing uses filler metals melting above 450°C (brass, silver alloys) for structural joints. Soft soldering uses low-melting alloys (tin-lead, tin-silver) below 450°C for electrical connections, plumbing, and sheet metal seams.
